# A. 스톱워치 & 시한폭탄

ATtiny85 + TM1650 4-digit 7세그먼트 + 피에조 부저로 구현한 **모드 전환형 타이머**입니다.

## 핀 맵

| 핀 | 용도 |
|---|---|
| PB0 / PB2 | 소프트웨어 I2C SDA / SCL (TM1650) |
| PB1 | 모드 전환 버튼 (디지털, GND 직결) |
| PB3 | ADC 입력 — 버튼 3개 (시간설정 / 시작 / 일시정지) |
| PB4 | 피에조 부저 |

## 핵심 구현

### 1. ADC 저항 분압 키패드 — 핀 1개로 버튼 3개

핀이 모자라 버튼마다 다른 저항을 달고 ADC 값 구간으로 판별했습니다. (10kΩ 풀업 필수)

| 버튼 | 직렬 저항 | ADC 값 |
|---|---|---|
| 미입력 | — (풀업) | > 950 |
| BTN1 시간설정 | 0Ω 직결 | < 50 |
| BTN3 일시정지 | 2.2kΩ | 100 ~ 300 |
| BTN2 시작 | 10kΩ | 400 ~ 700 |

### 2. Timer1 인터럽트 기반 10ms 틱

`ISR(TIMER1_COMPA_vect)` 에서 10ms 틱을 세고 10회마다 0.1초를 증감시킵니다.
스톱워치는 `MM:SS.d` 로 6000(10분)에서 롤오버, 시한폭탄은 설정값에서 카운트다운 후 폭발 연출.
ISR과 메인 루프가 공유하는 변수는 모두 `volatile` 선언으로 컴파일러 최적화에 의한 오동작을 차단했습니다.

### 3. 소프트웨어 I2C

`I2C_start()` / `I2C_write()` / `I2C_stop()` 을 SCL·SDA 토글로 직접 구현.
TM1650 명령(0x48 표시 제어, 0x68 DIG0)과 세그먼트 비트맵 테이블(`seg_CA[]`)로 숫자를 출력하고,
최상위 비트(DP)를 OR하여 초 단위 구분점을 표시합니다.
