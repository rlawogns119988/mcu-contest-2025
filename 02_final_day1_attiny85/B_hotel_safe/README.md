# B. 호텔 금고 (전자 도어락)

ATtiny85 + TM1650(디스플레이 **겸 키패드 스캔**) + 부저로 구현한 4자리 비밀번호 금고입니다.

## 동작 사양

- 비밀번호 4자리 입력 → 일치 시 `SUC` 표시 후 개방
- 비밀번호 변경 모드 → `CHA` 표시
- 오입력 시 `EEE` 표시 및 에러 카운트 증가, 5회 누적 시 잠금 경보
- **10초 무입력 시 입력 버퍼 자동 초기화** (타임아웃)
- 피드백 메시지는 2초간 표시 후 대기 상태 복귀

## 핵심 구현

- **TM1650 키 스캔**: 표시 명령(0x48)과 별개로 키 명령(0x4F)을 보내고 `I2C_read()` 로
  눌린 키 코드를 되받아옵니다. 즉 디스플레이 칩 하나가 출력과 입력을 겸합니다.
- **양방향 소프트 I2C**: 읽기가 필요하므로 `DDRB` 를 매 비트마다 입력/출력으로 전환하며
  오픈드레인 동작을 흉내 냈습니다 (A 과제의 단방향 구현에서 확장).
- **상태 머신**: 입력 대기 / 비밀번호 검증 / 변경 / 피드백 표시 / 잠금 상태를
  타이머 변수(`idle_timer`, `feedback_timer`, `tone_timer`)로 논블로킹 관리 —
  `_delay_ms` 로 멈추지 않아 표시 중에도 입력·경보음이 동시에 동작합니다.
- **세그먼트 문자 확장**: 숫자 0~9 외에 E, U, C, H, A, S, `-` 비트맵을 추가해 문자 메시지 출력.
